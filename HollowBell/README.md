# 钟誓 · Hollow Bell

**第一关：雾鸦隘口**。独立的中世纪奇幻横版动作游戏，Godot 4.7，Windows x64。

## 开始游戏

- 直接运行 `play/HollowBell.exe`；兼容图形驱动入口为 `play/Start-HollowBell.cmd`。
- VS Code「运行任务」选择 **试玩钟誓 · 第一关**（运行 `HollowBell/play/HollowBell.exe`）。
- 编辑工程：用 Godot 打开本目录的 `project.godot`。
- 运行不需要联网、账号或 Godot 编辑器。交付时可复制 `play/HollowBell.exe`。

## 操作

| 动作 | 键鼠 | Xbox 布局手柄 |
|---|---|---|
| 移动 | A / D、← / → | 左摇杆 / 方向键 |
| 跳跃 | Space；按住跳得更高 | A |
| 三段连击 | 连按 J / 鼠标左键 | 连按 X |
| 蓄力重击 | 按住 K / 鼠标右键后松开 | 按住 Y 后松开 |
| 长翻滚 | Shift / L | B |
| 短翻滚 | C / 鼠标中键 | RT |
| 格挡 | 按住 Q，贴身护盾 | 按住 LB |
| 弹反 | 新按 Q，起手 0.17 秒内迎击 | 新按 LB |
| 回复 | E | RB |
| 暂停 | Esc | Start |
| 全屏 | F11 | — |

标题可用鼠标或方向键 + Enter 操作；暂停页可调音量、查看操作、回检查点。切出窗口自动暂停。

长翻滚保留耗气 20、动作 0.48 秒、无敌 0.38 秒、约 5 米位移。短翻滚耗气 14，动作 0.30 秒、无敌 0.22 秒，速度平滑从约 15 降至 7，位移约 3.3 米；翻滚输入缓存 0.16 秒，轻击进行至 0.22 秒后可取消为短翻滚。

格挡是贴身收盾、弹反是向前拨挡，两者姿态不同。成功弹反获得 **1.0 秒无敌**，HUD 显示剩余时间；之后翻滚不会缩短原有保护。格挡卸力 0.16 秒，弹反卸力 0.24 秒（0.12 秒后可按 J / X 反击）；持续按住防御经过卸力不会重新开启弹反窗口。

三刀的剑弧对应下斩、上挑、终结斩；蓄力松键后接续已经蓄到的姿态，不重播起手。以上是实现与素材规格，实际连贯性以真机试玩为准。

## 第一关

**雾林古道 → 断桥回声 → 无声修道院 → 钟楼**。

沿途两座祈灯自动激活检查点并恢复资源。坠落损失少量生命并回到最近祈灯；死亡可重试。击败 Boss 后继续向右，走到最后的钟亭完成第一关。

共 **8 种敌人、15 场遭遇**，包含 Boss：

| 敌人 | 主要攻击 |
|---|---|
| 荆棘匍兽 | 低伏蓄力后扑击 |
| 锈剑侍卫 | 近身双斩 |
| 长枪守望 | 回枪蓄势后的长距离突刺 |
| 棘弩猎手 | 锁定瞄准线后发射弩箭 |
| 灯笼司祭 | 三枚错速扇形光球 |
| 石翼幼像 | 振翼、锁定落点、俯冲返航 |
| 重锤典狱 | 抬锤砸地与双向地波 |
| 守钟巨像·奥尔登 | 横扫、跃砸、三重钟波；半血进入第二阶段 |

## 素材与制作

- **16 张初版 image2.5-sunburst 原图**，每张 1536×1024；保留在 `assets/source` 根目录。
- 主角新版另有 image2.5 生成/编辑任务 **184–195 的 12 张候选**，保存在 `assets/source/hero_v2_candidates`：`flow_ab`、`flow_finish`、`counter_ab`、`counter_finish`、`stride_ab`、`stride_finish`、`defense_compact`、`defense_agile`、`motion_grounded`、`motion_agile`、`edit_flow_ab_flare`、`edit_flow_ab_sunburst`。
- 当前选用 **`stride_ab` + `stride_finish` + `motion_grounded` + `defense_compact`**，发布为 4 张 6×4 图集、**96 个实际姿态**；并非把候选的 288 帧全部用于游戏。旧 `hero_special` 的受伤、回复各 6 帧独立保留。
- 三段轻击各连续播放 12 姿态（前摇 / 有效 / 收招各 4），标签 `attack_0..2` 不在命中边界重置；伤害仍为 23 / 27 / 38。每类敌人仍有独立 24 帧图集。帧数与像素差异不是流畅度保证，需结合姿态衔接与真实试玩判断。
- 真实 3D 地形、石拱、柱廊、钟楼与水面，结合像素精灵、分层背景、光影和空气透视。
- 原创合成配乐：96 秒探索、80 秒 Boss、10 秒胜利乐句；17 种独立音效。采用鲁特琴、笛、弦乐、框鼓和铜钟的声学风格合成音色，**不是实录乐器**。
- `assets/audio/music` 为游戏用 OGG，`sfx` 为 WAV，`masters` 保留 PCM 母带；制作工具为 `tools/compose_audio.py`。
- 原图、母带、测试及 QA 文件不打入游戏。现有 `ForestGlow` 保持独立。

## 验收范围

- `tests/test_game.gd`：真实主场景的输入、战斗、跳跃、检查点、暂停、死亡与通关状态。
- `tests/test_player_v2.gd`：60/120 Hz 物理 × 60/120 Hz 渲染四组合，覆盖连续姿态、长/短翻滚、输入缓存、格挡/弹反和 1 秒保护；不是美术质量或真实 GPU 流畅度结论。
- `tests/test_enemy_contract.gd`：8 类 AI 的有效帧、前摇、打断、死亡、地形边缘和 Boss 阶段。
- `tests/playthrough.gd`：只发送按键的自动玩家，全关 15 次击败、Boss 第二阶段、零死亡；报告保留于 `qa/playthrough-repeat.json`。机器人读取内部状态来决策，不代表新玩家的难度或通关时间。
- `tests/test_assets.gd`：保留初版 16 原图、11 图集、28 转换输出契约；独立检查 4 张新版图集存在且不被旧转换覆盖。原图哈希、透明边缘、完整帧与锚点检查不等同于审美评价。
- `tests/test_audio_runtime.gd`：真实引擎混音、循环、静音、暂停衰减与快速曲目切换。
- `tests/render_capture.gd`：真实 ANGLE 渲染截图，位于 `qa/screens`。

`tools/verify_build.ps1` 默认 Static 阶段，只解析脚本、核对资源引用与图集文件头；Build 阶段无窗口导出 `play/HollowBell.exe`，**默认不执行打包程序**。运行时检查必须显式选择 Render / Regression 或给 Build 传入 `RunPackagedCheck`；本轮按用户要求不执行这些入口。`tests/desktop_check.ps1` 只接受交付 EXE 的 PID，`QuickRoll` 对应 C 键。

本轮只做静态/语法检查与导出；**不启动游戏、不执行功能回归或桌面验收**。静态结果见 `qa/player-v2-static.json`；旧版通关、截图和音频报告不能作为新版动作已通过的证据。

### 真机试玩重点（待用户验收）

1. 连按 J，检查三刀之间是否连贯、第二刀剑弧方向正确；蓄力 K 松键后不突然回到起手。
2. C / 鼠标中键做短翻滚，Shift / L 做长翻滚；试一下从攻击接翻滚、再接攻击是否顺手。
3. 持续按 Q 应是贴身格挡；迎击时新按 Q 应是前拨弹反，成功后有 1 秒护佑倒计时，接翻滚不截短保护。

是否真正更流畅、手柄 RT 是否适配，以及 1 秒保护的实际命中表现，需要这次真机试玩确认；未标记为通过。移交理由：D（用户明确选择在真机测试）。

当前远程 Windows 会话的 WASAPI 输出设备无法初始化；已验证实际引擎 PCM 混音，**未完成扬声器试听或目标机性能验收**。游戏仍保留正常系统音频输出，不为测试环境强制静音。
